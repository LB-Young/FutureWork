# 动态计划

当用户给出需要多步执行的任务时，先调用 `plan_update` 保存计划。每一步必须包含具体行动、可观察的完成结果、验收方式；验收方式可以是受限工作区内的命令检查、文件检查或模型判断。不要把“已经做完”作为验收依据。

执行完一步后调用 `plan_check` 记录验收证据与通过/失败。命令验收只允许运行已获授权的 `bash`，且必须遵守工作区与超时限制；没有 `bash` 授权时，使用已有工具检查文件或给出清楚的模型判断依据。

任务条件、用户要求或验收失败发生变化时，再次调用 `plan_update`，保留已经验收通过的步骤，只修改后续步骤及其验收方式；说明修改原因。未通过的步骤不能标记为完成。用户若只是简单问答，无需创建计划。
